模型配置教程 自定义提供方

以 New API / One API 兼容网关为例，一步步配置你的第三方模型

本教程适用于以下场景：

  • 你或你的团队有一个 New API / One API（或任何 OpenAI 兼容的 API 网关）
  • 网关地址类似 https://your-gateway.example.com:13000（内网或公网均可）
  • 你想在 DeepSeek Harness Desktop 里使用这个网关上的模型

第一步：打开模型设置页面

1
进入设置 → 模型

点击窗口右上角的 ⚙ 设置 按钮，或从系统托盘右键菜单选择「设置…」，进入设置页面。

在设置页面中，点击左侧或顶部的 模型 标签。你会看到已配置的提供方列表（如 deepseek-official）。

📋
设置页面 → 点击「模型」标签
（截图占位 — 实际界面以此为准）

第二步：添加自定义提供方

2
点击「添加自定义提供方」

在提供方列表底部，有一个 「添加自定义提供方」 或 「Add a custom provider」 按钮，点击它。

➕
提供方列表底部 → 点击「添加自定义提供方」

弹出一张空白卡片，包含以下字段：

第三步：填写网关信息

3
填写提供方参数

按以下表格填写卡片上的各个字段：

字段填写内容说明
Route / ID ai-router 唯一标识符，小写字母开头，用于区分不同提供方。可自定义，如 my-gateway
Base URL https://your-gateway.example.com:13000/v1 网关地址 + /v1 后缀（OpenAI 兼容接口的路径）
Display Name AI Router（可选） 在模型选择器中显示的名字，不填则显示 Route ID
API Key 你的 sk-xxx... 密钥 从网关管理员获取的 API Key
⚠ 注意：Base URL 一定要以 /v1 结尾，因为 DSH 使用 OpenAI 兼容协议时，接口路径为 /v1/chat/completions 等。

第四步：添加模型

4
从网关获取模型列表

填写完 Base URL 和 API Key 后，点击卡片上的 「获取可用模型」 按钮（或 "Fetch available models"）。

如果网关和 Key 正确，将弹出一个窗口，列出网关上的所有可用模型：

📦
弹出窗口显示模型列表
deepseek-v4-flash、deepseek-v4-pro、glm-5.2、glm-5.1
💡 提示：你也可以在添加提供方之后，随时点「获取可用模型」来刷新列表。

勾选你想使用的模型（至少选一个），点击确认。模型将出现在下方的列表中，展示各自的 模型 ID 和 名称。

第五步：保存并使用

5
保存配置，选择模型

确认模型列表无误后，点击卡片右上角的 保存 按钮。

  • 保存成功后，卡片会折叠显示为一行，状态灯变为 🟢 绿色（可用）
  • 返回主窗口，点击顶部工具栏的模型选择器
  • 在提供方下拉列表中，选择你刚添加的 ai-router
  • 在模型下拉列表中，选择 deepseek-v4-pro 或任意已添加的模型
  • 发送一条消息，验证模型响应是否正确
💬
主窗口顶部 → 点击当前模型名 → 选择 ai-router / deepseek-v4-pro

常见问题

❌「获取可用模型」失败，显示重试延迟

现象：点击「获取可用模型」后，页面提示 "重试延迟：XXXXms / 失败原因：Unexpected error: http2 request did not get a response"。

原因：这个网关是 New API / OpenAI 兼容协议，但 DSH 的提供方卡片选成了 amazon-bedrock（AWS Bedrock 协议），导致 DSH 用 AWS SDK 的 HTTP/2 通道去请求，而网关不识别 Bedrock 接口路径，连接被直接掐断。

解决：删除这张 Bedrock 卡片，重新按本教程添加为「自定义提供方」（OpenAI 兼容），问题即解决。

❌ 添加完成后，模型一直不响应

  • 检查 Base URL：确认末尾有 /v1，且地址可在浏览器中访问到网关页面
  • 检查 API Key：在终端中运行 curl -k https://你的网关地址/v1/models -H "Authorization: Bearer 你的key"，看是否返回模型列表
  • 日志排查：在设置页面点击「打开日志目录」，查看 main.log 中的错误信息

🔧 我想改用其他协议（如 Claude / Bedrock）

DSH 自带多个提供方适配器：

  • Amazon Bedrock — 原生 AWS Bedrock 协议（HTTP/2），适合直连 AWS
  • Anthropic — 直连 Claude API
  • Google Vertex AI — 直连 Google 云
  • 自定义提供方 — OpenAI 兼容协议（本教程的场景）

在「模型」设置页面，点击「添加提供方」下拉菜单，选择对应协议即可。每个提供方有独立的配置字段。
